# Mood Watch — 设计与复刻说明

> 本文件是 `Mood Watch` 的设计依据与实现契约：SwiftUI 工程与 Web 预览都必须严格按本文件实现。
> 复刻对象：桌面 `StressWatch 2.ipa`（`com.ideation.Stress` v3.4.8，UIRequiredDeviceCapabilities arm64，MinimumOSVersion 16.0）。

## 1. 净室复刻边界

| 项目 | 做法 |
|---|---|
| 结构与文案 | 从 IPA 的 `zh-Hans.lproj/*.strings`、`SOMStates.json`、`SOMTags.json` 中还原信息架构与文案风格，**重新撰写**代码实现 |
| 视觉 | 参考其品牌调性（薄荷绿、米白底、圆角大卡片、手绘感表情），本项目的图标、配色、组件均为**原创绘制/实现** |
| 资源 | **不复制** IPA 内的图片、Lottie JSON、字体、音频（`Assets.car` 133 MB、`*.watchface`、`Sora-*.ttf` 等一律不打包） |
| 二进制 | 不反编译、不注入、不二次打包原 App；App 名称、Bundle ID、代码全部是新的 |

App：**Mood Watch**，Bundle ID 默认 `com.moodwatch.app`，iOS 16.0+，SwiftUI，零第三方依赖。

## 3. 信息架构

底部 5 个 Tab（与 StressWatch 对齐，图标用 SF Symbols 原创组合）：

| # | Tab | SF Symbol | 内容 |
|---|---|---|---|
| 0 | 今日 | `sun.max` | 压力仪表盘、今日 HRV、心情、关键行动、昨日入口 |
| 1 | 趋势 | `chart.bar` | 14/60 天等级柱状趋势、等级分布、30 天平均 HRV / 静息心率 |
| 2 | 行动 | `checkmark.circle` | 心情记录时间线、习惯打卡、行动与压力洞察入口 |
| 3 | 健康 | `heart.text.square` | 身体年龄、睡眠、静息心率、步数、最大摄氧量、影响因素 |
| 4 | 设置 | `gearshape` | 等级名称自定义、每日目标、通知、隐私、关于 |

首次启动进入 4 页 Onboarding（隐私优先 → 工作原理 → 健康授权 → 完成），可跳过；设置内可重看。

## 4. 压力状态模型

四档 + 三档边界态（文案取自原 App 语义，重新组织）：

| 等级 | 名称 | 色 | 一句解读 |
|---|---|---|---|
| 1 | 压力过载 | `overload` | 此刻你的 HRV 低于日常水平，身体在硬扛，先停下来喘口气。 |
| 2 | 注意压力 | `warn` | 略低于日常水平，别硬撑，给自己一点放松的余地。 |
| 3 | 状态正常 | `normal` | 处于日常水平，张弛有度，保持节奏就好。 |
| 4 | 状态优秀 | `great` | 高于日常水平，身心放松，状态在线。 |
| na | 暂无今日数据 | `muted` | 今日佩戴时长不足，保持佩戴即可积累数据。 |
| over | 无定义 | `muted` | HRV 过高（>180ms）不纳入平均值，注意休息。 |

**综合压力指数**（0–100，越高越紧张）：以近 30 天 HRV(RMSSD) 均值为基线 `μ`、标准差 `σ`，对当前值 `x` 求 `z = (x-μ)/σ`，映射 `index = clamp(50 - z*18, 0, 100)`；
`index ≥ 62` → level 1；`52–62` → level 2；`38–52` → level 3；`< 38` → level 4。仪表盘同时显示 HRV 绝对值与「近 30 天平均」。

## 5. 屏幕细则

### 今日

1. **顶栏**：左「Hi, 你 👋」，右日期（`11月25日 周二`）+ 数据更新时间「数据更新于 20:41」。
2. **压力仪表盘卡**（高 320）：
   - 270° 环形进度（`Circle().trim`），底色 `surfaceAlt`，进度色为当前等级色，线宽 22，端点圆角。
   - 中心：等级名（`title`）+ 压力指数（`display`，例如 `58`）+ `HRV 42 ms` + 「最近一次 20:15」。
   - 环右侧 4 段刻度：`过载 / 注意 / 正常 / 优秀`，当前段加粗并着等级色。
   - 卡底一行：`今日综合压力状态` + 「详细解读」按钮（展开当等级解读文本，`body`）。
3. **今日 HRV 趋势卡**：迷你折线（平滑曲线 + 渐变填充），X 轴 `00:00 / 06:00 / 12:00 / 18:00 / 24:00`，Y 轴 `0–180 ms`；右上角显示 `近 30 天平均 58ms`。
4. **心情卡**：标题「你现在的感受如何？」+ 5 个心情圆点（😄 🙂 😐 😕 😣，选中放大 1.1 倍并描边）+ 「记录感受 ›」打开 MoodLogSheet。
5. **关键行动卡**：4 个习惯行（🌞 晒太阳 / 💧 喝水 / 🧘 呼吸正念 / 😴 睡够 7 小时），每行右侧小环形进度 + `12/20 分钟` 之类数值，进度色 `mint`。
6. **昨日回顾卡**：浅色提示「或许此刻你想查看：昨日（11月24日）的压力状态」+ 右箭头。

### 趋势

1. 顶栏标题「趋势」+ 分段控件 `14 天 / 60 天`。
2. **等级柱状图**（高 200）：每天一根圆角柱，高度 = 压力指数，颜色 = 当天等级；叠加近 30 天均值虚线。
3. **分布卡**：4 行，每行 `等级名 · n 天` + 横向进度条（等级色）。
4. **两个指标卡**（并排）：`近 30 天平均 HRV 58 ms`、`静息心率 62 bpm`，各带 7 点迷你折线。

### 行动

1. 顶栏「行动」+ 右上角「＋ 记录」。
2. **今日心情时间线**：卡片列表，每条 = 时间 `20:15` + 表情 + 状态名（如「压力」）+ 标签胶囊（如 `🧑‍💻 工作`、`☕ 咖啡因`）+ 备注文字；空态给引导文案。
3. **习惯打卡**：2×2 网格卡（呼吸正念 5 分钟 / 晒太阳 20 分钟 / 喝水 2000 毫升 / 咖啡因 < 100 mg），点击切换今日完成，完成态 `mintSoft` 底 + ✓。
4. **洞察入口**：`行动 v.s. 压力趋势 — 透视生活习惯如何改变你的压力趋势`，右侧箭头（点击弹 Alert「数据积累中」）。

### 健康

1. **身体年龄卡**（主视觉）：大号「28 岁」+ `实际年龄 30 岁 · 年轻 2 岁` + 衰老速度胶囊（`年轻中`）。
2. **影响因素**列表：睡眠时长、睡眠一致性、静息心率、步数、最大摄氧量、力量训练时长，每行 `名称 / 数值 / 对年龄的影响（-1.2 岁 之类，正影响 mint，负影响 overload）`。
3. **睡眠卡**：`7 小时 12 分` + 睡眠质量 `82 分`（环比 +4）+ 4 段睡眠阶段横条。
4. 底部免责声明小字：`Mood Watch 不是医疗设备，所提供信息仅供参考，不能替代专业医疗诊断。`

### 设置

分组列表：`压力状态名称`（4 档可改名，编辑后仪表盘同步）、`每日目标`（晒太阳/喝水/呼吸/睡眠）、`通知`（压力提醒、每日小结）、`隐私与数据`（本地存储开关、导出 JSON、清空数据）、`关于`（版本 1.0.0、复刻说明、重看引导）。

## 6. 动效

- 环形进度：`.easeOut(duration: 0.9)` 从 0 到目标值。
- 数值：`contentTransition(.numericText)`（iOS 17+ 用 availability 判断）。
- 卡片入场：`opacity` + `offset(y: 12)` 依次 40 ms 延迟。
- Tab 切换：默认 `TabView`，不加自定义转场。

## 7. Web 预览与 SwiftUI 的对应

`web/index.html` 用同一套 token（CSS 变量同名）、同一套文案与布局，仅用于**验收界面**：iPhone 15 尺寸画框（393×852），可切换 5 个 Tab、可点开心情记录弹层、可切换深浅色。它不是产品交付物的一部分，但必须与 SwiftUI 版本一致。
